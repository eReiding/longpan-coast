- `V` 切换第一人称/第三观景；无人物模型。
- `M` 目的地列表、`G` 下一景点，立即跳转；自动导览可以沿真实步道移动，但可随时停止。
- 具体相机pos/target由controls根据field高度与太阳方向生成，不能将角色脚底当成摄影机。
- 不把参考照片的摄影机内外参编造成已知值，不报告虚假的像素拟合RMS。

## 模块顺序

`geo/data/field` → `controls/ui` → `road/trail/terrain` → `flora` → `water/rocks/wildlife` → `sky/cloud shadows` → `solar/audio/playback/capture` → 逐机位截图。

## 变更日志

- 第二轮：使用真实OSM岸线和道路，纠正旧正弦岸线造成的距离与层次错误。
- 移除主场景人物，保留无人物第三观景并新增第一人称。
- 修复 `createUI()` 返回不同对象造成的按钮控制失效，所有目的地使用同一控制器。
- 新 ecologyAt() 用高程、坡向、盐风、遮蔽与道路距离分区，不再只按平面随机撒草。
- 海上日出与内陆日落分离；云影、枝干阴影、音景、翻卷碎浪与可播放时间轴作为同一世界的动态系统。
- 第三轮：默认左岸第一人称，沿海岸构图让地面在左、海在右；大HUD默认隐藏。
- 连续游线为入口→OSM连接步道→海岸步道→高位左岸→安全下岸→潮池。`field.config.route`为路线事实源，渲染与导览共用。
- 主左岸可见坡面的连续低灌丛优先于全图植物总数；近岸网格加密，礁石、地被、云层与海水反射共同构成空间层次。
- 第四轮：默认从台26公路开始，游线增加公路→木栈道→公园入口段，总长约1.68km；地图显示这条真实路线。
- 双指与B键进入斜俯视，视线从当前位置平滑转向游线核心与海岸；detailBounds限制最高机位，避免看到未建模区域。
- 云层取消贴屏代理，直接在主场景raymarch世界空间云；地图和时钟为SVG，不增加canvas。
- 叶片具有独立UV、叶脉与叶面细节；高大植物加入碰撞索引，小径按冠幅净空，路面边缘和断面不再等宽平直。
