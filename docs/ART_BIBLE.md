# 龙磐海岸美术契约 · 第二轮

参考：用户图2–25及 `refs/` 内部研究图。照片只用于学习，不进入运行时材质，不作为假3D背景。

## 空间与风格

- 本场景是有真实地理约束的视觉重建，不是测绘。入口、公路、步道、岸线来自OSM；高程由公开DEM约束；细节由代码生成。
- 核心不是“一个海边草坪”，而是公路入口→红土小径→疏密植被→高位左岸→曲折下台→潮池的连续游线。
- 主打画面是高位左岸：太平洋在左，右侧礁岸与台地层层下行。近景必须有肉厚叶、剑形叶、草叶、红土、湿礁等可辨识结构。
- 盐风台地以低灌丛和草为主；较高海岸灌丛只在中段步道、避风波地和内陆谷地出现。不能用森林、棕榈球或均匀草坪填满地图。

## 地理和太阳

- 原点 `120.849472, 21.927806`；+X东、+Z南、Y上。
- 公路入口约111m、台地转折约60m、左岸高位约75m、临海观察约35m；真实高差是构图和生态分区的依据。
- 龙磐朝东面向太平洋：**海上日出，内陆日落**。时间轴共享太阳计算，禁止为了“海上落日”把太阳移到错误方位。
- 晴天的阴影是冷灰蓝，小径阴影也保留叶片和土壤细节，不死黑。日落低角度光应产生长影和明暗分层，不是全屏橙色滤镜。

## 地点与材质

- 公路：约6m沥青、双黄线、白色边线、路肩和局部金属护栏；顺真实弯道，不强行拉直。
- 小径：约1.2m红土/薄土步道，边缘不规则，与珊瑚礁凸起共存；两旁形成疏密变化的植被，不堵路。
- 台地：绿色与干黄草混生、林投剑叶、草海桐肉厚圆叶、琼麻厚硬叶簇、马鞍藤紫花与匍地叶、局部芒草穗。
- 谷地：较高海岸灌丛、海蚀裂沟、远景山丘和大气透视，不能与开阔草原同一密度。
- 礁岸：溶蚀孔隙、层理、地衣、灰黑湿面、潮水水痕、少量沙湾；拒绝光滑圆饼与均匀泥裂。
- 海水：FFT连续波面、沿真实岸线推进的短段翻卷波峰、局部飞沫、浅蓝绿到深蓝的层次；白沫有破碎纹理，不是规则丝带。

## 曝光与色彩目标

- 晴天：p02 18–35，p10 40–65，p50 100–130，p90 175–210，p98 225–248。
- 小径阴影单独验收，暗部仍需辨识叶形、红土和岩石，p02建议不低于6。
- 海水 navy/cobalt、近岸blue-green/turquoise，泡沫白而不荧光；植被深绿、橄榄绿、少量干黄和红土，不高饱和荧光绿。
- 对照必须同机位、同天气。使用 `colorstats`、`satstats`、局部crop与锚点sample，不以“看起来还行”替代数字。

## 本轮验收

- 任一机位无人物；第一人称与第三观景切换连续，点击目的地立即生效。
- 入口、步道、左岸、右岸、近岸、日出、日落分别截图，先过 stills 再制作最终剧场录屏。
- 固定1:1桌面分辨率并读取canvas尺寸，不拿fit面板缩放后的读数充当桌面性能。
- 音景需要用户手势；录屏含Opus音轨（声景开启时），连续两次录制可用。
- 不把“有实例”当作“视觉完成”：真实叶片、阴影、海浪、鱼和鸟必须能在实际画面里观察。

## 第三轮基线与目标

- 基线 `qa/round3/baseline-overlook.png` 来自真实浏览器，确认了大片无植被地表、粗糙网格、柱状云和规则波面；旧拼图 `qa/round3/reference-montage.png` 仅作海岸分区参考，不作为同曝光照片。
- 基线与拼图的全局亮度p50为92 vs 69、平均分区亮度差40.1，说明不能直接套用第二轮回曝光区间；第三轮优先按天空/海/地被三个区域分别比对，避免为了匹配旧暗图压暗云层。
- 新图左侧地被必须连续，裸土只是断裂的小斑块；海在右侧，近岸blue-green与远海navy有空间层次，云底冷灰、云顶明亮且有真实厚度。
- 任一主视角不可见规则白色波线、柱状云、均匀地面网格或明显重复植物；近景叶片与礁石应能在局部crop中辨识。
- 默认进入左岸，无开场、无大HUD；能连续步行至水边，速度提升不能穿透碰撞或越过深水。
- 验收仍执行 `colorstats → satstats → crop → sample`，以最终同机位新参考为准；未达标不宣称照片级。

## 第三轮集成记录

- 修正实例色与叶色相乘造成的过暗植物，扩大低灌丛冠幅；核心坡面向shore 570m延伸，保留步道与岩石裸地。
- 可见植被按真实相机统计持续降载，地形使用独立低精度投影层，避免高细节地面重复进入阴影pass。
- 云使用64³噪声和24步体积计算，经0.46比例HDR缓冲合成，不是固定云图；地面和水面共享云密度场。
- 水面加入Snell折射和光程吸收，近岸沿真实岸线加密，三角形绕序经数值检查全部为+Y。
- `qa/round3/overlook-final.png`：p02/p10/p50/p90/p98为49/61/103/182/195；天空锚点RGB 175/179/189，海水105/125/157，地面63/75/57。与旧机位曝光不同，不作为参考照片匹配通过证明。
- 日落剧场使用真实日落时刻的太阳朝向与高位机位，暗部补光独立于晴天。`qa/round3/sunset-final.png`保留太阳与前景叶形。
- `qa/round3/flora-crop.png`用于近景检查。植物叶形、枝干和地表仍可见程序生成痕迹，下一轮不能把这些截图称为实拍级。

## 第四轮修正

- 默认从台26公路附近开始，圆形SVG地图显示真实游线；可切换24小时时钟并拖动选时。
- 双指/滚轮与B键进入斜俯视，视线对准完整游线；高度由detailBounds限制，不展示未建模边缘。
- 第四轮删除贴屏cloudProxy/cloudTarget/renderClouds路径。云改为128³噪声、主场景世界空间raymarch，约18步与单路太阳密度采样；云量降低，保留蓝天、云底和侵蚀边缘。
- 每片叶具有UV与aLeaf，生成中脉、侧脉、斑驳和粗糙度差异；叶形圆钝化。500株高大植物登记碰撞，冠幅增加步道净空。
- 海水保留FFT与折射，并加入浅水shelf散射，形成近岸蓝绿至远海深蓝渐变。
- 小径采用独立不规则边缘、断面与中央踩踏区；曝光默认1.08，饱和度1.20，保留AgX高光。
- `qa/round4/`保存实际入口、俯瞰、叶片与海岸检查。功能通过不等于已达到照片级；叶形、云形和地形材质仍需继续按用户反馈精修。

## 参考海岸配色与空中移动

- 按用户提供的海岸照片，远海使用更深的navy，近岸保留青绿/青蓝，降低水面灰白反射占比，泡沫仍保留冷白对比。
- 独立礁石和地表岩石统一为深灰/炭灰，保留孔隙、湿润反光、地衣和较亮断面，不再以浅奶油色为基底。
- 植被增加枝条数量、5组几何变体和每株位置种子的形态差异，叶色偏深绿，保留干草、裸土与叶脉。
- 鸟瞰时WASD按相机水平前方移动，W为60m/s、Shift为120m/s；地面W为9m/s、Shift为22.5m/s，导览为18m/s。空中不受地面坡度/植株碰撞阻挡，但仍受detailBounds限制，返回地面恢复碰撞。主动进入鸟瞰时按当时太阳方位构图；之后拖动时钟或昼夜变化只更新光照，不再自动改变相机朝向，太阳落下后不强行显示。
- 昼夜循环约48分钟；日出/日落剧场90秒。播放计时应使用分钟:秒数，支持超过59秒的完整时间轴。
- 减少干草褐斑和枯屑色混合，公路与入口补充5200株低灌丛，保留道路、步道、岩石和裸土净空。
- 海面高光限制为0.78倍且封顶3.0，太阳盘同步降亮，bloom降低，避免整片白色光柱。
- 沥青增加多尺度颗粒、细裂缝、修补色差、磨损和凹凸/粗糙度，提升开场近景质感。
- `qa/round4/palette-reef.png`记录深灰礁石与青绿浅水；配色以参考方向修正，不声称已做逐像素照片匹配。
